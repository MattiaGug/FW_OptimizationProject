## About The Project

This repository contains implementations, experiments, and analysis related to **Frank-Wolfe optimization algorithms** and their variants. The goal is to study convergence behavior, performance, and practical applications on convex optimization problems.

Typical contents include:

* Mathematical formulation of optimization problems
* Algorithm implementations
* Experiments and benchmarks
* Visualizations and reports

## Getting Started

To get a local copy up and running follow these simple steps.

### Prerequisites

* Python 3.9+
* pip

### Installation

1. Clone the repo

   ```sh
   git clone https://github.com/MattiaGug/FW_OptimizationProject.git
   ```
2. Install dependencies

   ```sh
   pip install -r requirements.txt
   ```
